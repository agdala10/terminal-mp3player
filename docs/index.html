PASO A PASO

Instálalo en menos de un minuto.

El proyecto ya trae yt-dlp, ffmpeg y ffprobe incluidos.

01

Clona el repositorio

git clone https://github.com/agdala10/terminal-mp3player.git
cd terminal-mp3player
02

Instala para todos los usuarios

sudo bash install-system.sh
03

Ejecuta

terminal-mp3player

Alias: tmp3, winamp, term-winamp.

04

Pon tu música

mkdir -p ~/Music/terminal-mp3player
cp ~/Descargas/*.mp3 ~/Music/terminal-mp3player/

¿Prefieres no instalar globalmente? Usa python3 -m venv .venv && .venv/bin/pip install -r requirements.txt && ./run.sh.

CÓMO SE USA

Playlist, YouTube y descarga.

01

Agregar un link de YouTube

Pulsa u o el botón [URL], pega la dirección y da Enter. El título aparece automáticamente en la lista.

02

Escuchar sin descargar

Da Enter sobre la pista URL. Se descarga a caché y suena con la mejor calidad; al terminar pasa a la siguiente.

03

Guardarla en tu carpeta

Haz clic en el icono ↓ (o d). El audio se guarda en ~/Music/terminal-mp3player/ y se convierte en pista local.

04

Crear listas separadas

Pulsa t, escribe un nombre y Enter. Cambia entre listas cuando quieras; Supr las borra.
